# Publicação no GitHub — somente os experimentos

1. Crie uma conta em https://github.com/signup caso ainda não possua.
2. Em https://github.com/new, crie um repositório com o nome sugerido `ebralc2026-experimentos-orange`.
3. Escolha **Private** se quiser conferir arquivos e direitos antes da divulgação pública. Não inicialize com README.
4. Extraia o ZIP entregue e entre na pasta `EBRALC_2026_Experimentos_Orange_GitHub/`.
5. Na página do repositório vazio, escolha **uploading an existing file** (ou **Add file → Upload files**, quando disponível) e arraste **o conteúdo da pasta**, incluindo as pastas `experimentos`, `ferramentas` e `workflows` e os arquivos Markdown.
6. Aguarde o carregamento, confira a lista e clique em **Commit changes**.
7. Verifique se o `README.md` aparece na página inicial e se os seis manuais abrem.
8. Para tornar público depois, use Settings → General → Danger Zone → Change repository visibility, revise antes direitos autorais.

**Não envie arquivos DOCX/PDF do artigo-tutorial nem o Volume VII:** a estrutura deste pacote não inclui esses documentos.

Para arquivos grandes, limites do navegador, ou upload com muitos arquivos, use GitHub Desktop ou a integração GitHub depois de conectar sua conta.
