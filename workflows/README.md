# Workflows Orange (`.ows`)

Este pacote **não contém arquivos `.ows` validados**. Os manuais explicam a montagem manual das conexões entre widgets. Caso um fluxo seja reconstituído e testado efetivamente em uma instalação do Orange, poderá ser acrescentado aqui com versão do ambiente, entradas, saídas e data de teste. Não há substitutos fictícios.
